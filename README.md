Mini User Management Dashboard 

Developed a Mini User Management Dashboard using HTML, CSS, Bootstrap, and JavaScript.
This dashboard allows users to view, add, and manage user information dynamically. JavaScript is used to handle adding users through a modal form and updating the user list without refreshing the page.
The design is responsive and user-friendly, with a sidebar and navbar for easy navigation. This project helped me strengthen my skills in frontend development, DOM manipulation, and Bootstrap

Skills: HTML5 · Cascading Style Sheets (CSS) · Bootstrap (Framework) · JavaScript
